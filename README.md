# YinYang Android releases

Yin Yang EQ Lab maintains this repository for official Android downloads.

| App | Purpose |
| --- | --- |
| YinYang APK Manager | Downloads signed updates, applies compatible incremental patches, and sends verified builds to Android for installation. Requires Android 9 or later. |
| YinYang Companion App for Qudelix 5K | Controls the original Qudelix 5K, manages PEQ and channel matching, and runs blind listening comparisons. Qudelix 5K Plus support is coming soon. |

See the full list of available controls, YinYang additions, and the mixing and measurement research. [Android feature guide](FEATURES.md)

## Review builds

Open Releases while signed into an authorized GitHub account to review the APKs. The release catalog lists the package name, version and SHA-256 for each file. The Manager checks its embedded publisher certificate against each candidate before offering installation.

The GitHub edition uses an unauthenticated release feed intended for public distribution. While this repository is private, use the separate paired Manager for automatic updates on registered test devices.

The Android applications are built in the Lab development workspace. This repository holds the distribution records and signed release assets.
